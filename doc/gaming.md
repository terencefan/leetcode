
# Personal Statement

在过去的六年间，我一直从事 Azure SignalR 和 Azure WebPubSub 的研发工作。这两项服务本质上都是 WebSocket 解决方案，其中 SignalR 作为建立在 WebSocket 之上由微软 .NET 实现的应用层协议，其功能定位与 gRPC 或 Thrift 类似，主要实现双向 RPC 调用，而 WebPubSub 则更侧重于群组订阅/发布模型。

游戏行业曾是我在探索业务拓展方向时的重点考察领域，但我很快发现云计算和游戏开发之间的技术重点并不相同。问题核心在于 WebSocket 基于 TCP 协议的特性————其内置的重传机制确保了高可靠性，适用于多数场景，却难以满足游戏对超低延迟的严苛要求。而基于 UDP 的 QUIC，HTTP/3 及 WebTransport 作为由正在发展的新兴技术则能解决这一问题，我认为，无论是实现基于 QUIC 的 SignalR 服务，还是推出专门的 Azure WebTransport 服务，都将是我们技术演进的重要方向。

遗憾的是，受中美关系紧张局势影响，微软决定将我们半数工程师团队迁至澳大利亚，而我由于家庭原因无法前往，随着核心团队成员及负责人的离开，我深感失去了与这个团队共同成长的机会。

我必须坦言，在收到招聘信息之前，我对TGC（Thatgamecompany）并不熟悉，但他们的作品《风之旅人》却在我的生命中扮演了特殊角色。在我与女友相识初期，为了寻找一款能让我们共同沉浸于游戏艺术氛围的作品，我特意选择了《风之旅人》，甚至不惜将PS4从家中搬到公司会议室，只为创造两人独处的体验。这款游戏没有辜负我的期待——从午后到夜晚，我们完全沉浸在游戏的世界中。令人惊讶的是，几乎从不玩游戏的她竟一口气通关了整个旅程。如今，她即将成为我的妻子。因此，当从招聘人员那里得知TGC正是《风之旅人》的开发者时，我不禁由衷感叹："啊，原来就是那家公司啊！"

游戏作为我生活的一部分，可以说是几乎从出生开始到现在都一直陪伴着我。以近期让我印象深刻的《最终幻想 7: 重生》来说，克劳德能让我回想起小学时逃值日去游戏厅里偷玩 PS 被老师抓到的往事，而扎克斯则能唤起我高中时为攒钱购买 PSP 而每天饿着肚子攒五块钱的记忆。至于《精灵宝可梦》，它更是能让我回忆起小学第一次数学竞赛获奖收到的 GBC 掌机。或许 Game Freak 做游戏的技术确实不怎么样，回合制战斗也早就落后于时代，但它为无数人带来了最初的游戏感动————原来电子游戏能够构建一个完整的新世界。

我本人，则是一个能被游戏音乐打动的人。《尼尔：机械纪元》在发行初期对国区突然涨价的行为曾让我十分不满，但当我听到《Amusement Park》的时候，乐曲开篇的八音盒、大提琴和手风琴起初让我联想到常见的宗教音乐风格，而进入主歌第二段后，小提琴的频繁离调和钢琴三连音的加入，这种刻意营造的不和谐感开始让我感到好奇。随着副歌部分转为进行曲式，音乐开始迸发出力量感，而这种力量感却在副歌结束后戛然而止，仿佛预示着某种毁灭的降临。等到乐曲第二次进入主歌，原本钢琴的三连音被军鼓和电子噪音替代，这个变化终于让我迫切的想要了解：究竟是种什么样的绝望笼罩这这个游乐园，竟需要音乐家使用如此撕裂的音乐语言？当然《尼尔：机械纪元》没有让我失望————这个游乐园是被病毒感染的机械生命对人类欢乐的拙劣模仿，三连音代表华尔兹，进行曲式代表盛装游行，而离调、减七和弦和电子噪音的不和谐，则预示着这种模仿注定徒劳的悲剧本质。《尼尔：机械纪元》通过精妙的音乐设计实现了场景情绪的无缝转换：钢琴与小提琴营造非战斗时的静谧氛围，军鼓与电子噪音渲染战斗时的紧张节奏，8-bit 音效则精准表现骇客入侵的数字空间。三种音乐的无缝切换不仅完美契合游戏场景，更体现了音乐设计与游戏体验的高度融合。

我始终认为，在游戏中，游戏性代表是否有趣，美术则塑造沉浸体验，这些构成了娱乐性的基础。而艺术的本质是情感共鸣，音乐作为情绪的载体，正是一个游戏是否能升华为艺术品的关键。选择《风之旅人》作为和女友一起玩的第一个游戏，不仅仅因其优美的画面和简洁的交互，更因它用吟唱作为交互方式的创新，以及音效与环境音乐的完美融合。这种试听与情感的交融，是我做出选择的重要理由。

如果让我用一个词来形容 TGC，那就是尊敬，我深知独立游戏制作的艰辛，也明白主流市场对游戏艺术价值的漠视。但正因如此，这份坚持才更显珍贵，逆流而上需要勇气，重塑大众认知更需要信念。TGC 从诞生之初便带着艺术与理想主义的烙印，注定会成为游戏史上真正意义上的“那家游戏公司”。

I would be honored to be part of this historic moment.
